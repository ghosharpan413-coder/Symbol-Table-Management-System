# Symbol Table Management System

## Project Overview

The Symbol Table Management System is a Python-based
GUI application developed to demonstrate the concept
of symbol table management in compiler design.

The system uses a hash-based dictionary to store and
manage identifiers, data types, values and scopes.

## Objectives

- Understand symbol table management in compilers.
- Implement hash-based identifier storage.
- Perform efficient symbol table operations.
- Implement basic scope management.
- Prevent duplicate and invalid identifiers.

## Features

- Insert new symbols
- Search existing symbols
- Update symbol information
- Delete symbols
- Display all symbols
- Global and Local scope management
- Duplicate identifier detection
- Data type validation
- CSV file export
- User-friendly graphical interface

## Technologies Used

- Python 3

- Python Dictionary (Hashing)

## Installation and Execution

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

    python symbol_table.py

No external Python libraries are required.

## Limitations

- Supports basic Global and Local scopes.
- Symbols are stored temporarily in memory.
- Does not implement a complete compiler.
